# Arrangement & Structure Reference

## Principles
- **Phrasing**: everything moves in 4s — 4-bar phrases, 8-bar sections, 16/32-bar blocks. Change something every 8 bars, something small every 4. Dance music: small change every 8, bigger every 16, new section every 32.
- **Energy curve**: contrast is the tool. Each section should differ from its neighbor in at least two of: element count, register, density, filter, dynamics.
- **Tension/release**: build (add, rise, filter open, snare roll) → moment of silence or a pickup → release (drop/chorus: full kit, sub, hook). The release is only as big as the removal before it.
- **One new idea per section**; a hook must return at least 3 times.
- **Frequency slots**: sub (808/sub) · low (kick, bass) · low-mid (chords, guitars) · mid (vocals/lead) · high (hats, air). Layer one thing per slot per section; add a slot to lift, remove one to breathe.
- Loop → song: take the 4/8-bar loop, then subtract for intro/verse (fewer elements), add for chorus/drop, mutate for bridge/breakdown, subtract again for outro.

## Section recipes
| Section | Do |
|---|---|
| Intro | 1–2 elements; hint the hook (filtered/muted); establish tempo/groove; DJ intros = kick + hats only |
| Verse | Rhythm section + one harmonic element; leave mid range open for the vocal/lead; fewer hats |
| Pre-chorus | Add an element every 2 bars; rising line or pedal bass; snare roll last 2 bars; cut the kick last bar |
| Chorus / drop | Everything in; hook up front; widen (doubles, pads); highest register; crash on bar 1 |
| Post-chorus | Hook riff instrumental (pop/EDM); dance-floor payoff |
| Bridge / breakdown | New chord (borrowed iv, bVI), new texture, drop drums or halve the groove, key/mode shift, filter everything, half-time |
| Build | 8–16 bars: pitch riser + white noise swell, snare rate doubling (quarters→8ths→16ths→32nds), high-pass sweep up, remove sub, 1 bar silence / vocal chop before the drop |
| Last chorus | Modulate up a whole step (pop), add counter-melody, ad-libs, double-time hats, or strip to vocal + claps for 4 bars then slam back |
| Outro | Reverse the intro; DJ outro = 32 bars drums-only; fade or hard stop on the 1 |

## Transitions toolkit
Risers (noise, pitch), reverse cymbal into the 1, drum fills (see drum-patterns.md), 1-beat/1-bar silence, filter sweep (LP closing on the last 4 bars, HP opening), tape stop, vocal chop or FX hit on the "and" of 4, snare roll, crash + kick on the downbeat, dropping the sub for a bar, delay throw on the last word, half-time to double-time switch.

## Automation moves (Ableton `write_automation`)
- Auto Filter Frequency: LP sweep 200 Hz → 20 kHz over the build; HP sweep on the breakdown.
- Reverb send up on the last bar of a section, back to 0 on the drop.
- Utility Stereo Width narrow in verses, wide in chorus.
- Track volume −3 dB in verses vs chorus on pads/chords.
- Delay feedback up on the last vocal word.
- Tempo ramps only for outros/intros (rare).

## Loop-to-arrangement workflow in Live
1. Build the full 4/8-bar loop in Session view (all elements).
2. `duplicate_to_arrangement` the loop at each section start; delete elements per the section recipe (`delete_arrangement_clip` shifts later indices — work end-to-start).
3. `create_locator` at every section ("Intro", "Verse 1", "Drop").
4. Write automation, fills, transitions.
5. `set_loop` to audition one section; `record_section` to bounce.
