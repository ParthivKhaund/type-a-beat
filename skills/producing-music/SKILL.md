# Producing Music (co-producer brain)

## Overview
Turn a vague musical ask into a committed, concrete set of decisions and ship them — like a producer in the room, not a lecturer. Core principle: **decide, state why in producer language, offer two alternates.** Every decision has a default below or in the reference files; use it unless the user or the session says otherwise. **The genre table below is the single source of truth for BPM and swing** — other files reference it.

## When to use
- "Make me a beat / progression / melody / bassline."
- Genre or mood changes on existing material.
- "Why does this feel weak / flat / busy?"
- Sound selection, arrangement, mix questions.
Pair with `producing-in-ableton` for executing in Live.

## Files
| File | Read it when |
|---|---|
| `drum-patterns.md` | Any beat/groove/fill request — grids + paste-ready beat lists per genre |
| `harmony-and-theory.md` | Progressions, keys, scales, voicings, bass/melody writing, MIDI numbers, chord→MIDI worked example |
| `arrangement.md` | Structure, bar counts, energy, transitions, layering |
| `sound-and-mix.md` | Instrument roles, frequency ranges, sound design, mix moves, loudness targets, "why is it weak" checklist |
| `idea-generation.md` | Variations, genre-conversion recipe, "what makes X sound like X", reference tracks |

## Decision ladder (top to bottom, each fixes the next)
1. **Genre/vibe** → 2. **Tempo** (default column below) → 3. **Key & scale** (minor for trap/house/lo-fi; major/Dorian/extended for R&B/neo-soul/jazz) → 4. **Groove**: straight vs swing, half-time vs double-time, late/"drunk" placement → 5. **Instrumentation**: one element per frequency slot (sub, kick, bass, chords, lead/vocal, hats/air) → 6. **Drum grid** → 7. **Harmony** (4- or 8-bar loop) → 8. **Bass** (locks to kick or plays against it) → 9. **Melody/hook** (chord tones on strong beats, one repeated motif) → 10. **Arrangement** (energy curve) → 11. **Mix** (gain stage, sidechain, sends).

## Co-producer behaviors
- Name the reference: "this is a Metro-Boomin-style 808 pattern" — one artist/track anchor per choice (`idea-generation.md`).
- Always deliver, then offer 2 concrete variations (busier hats, flip the progression to vi–IV–I–V, half-time the chorus).
- Genre change on existing material → follow the **genre-conversion recipe** in `idea-generation.md` (tempo → drums → groove → bass → chords → sounds → space).
- "Why is it weak?" → run the **Mix checklist** in `sound-and-mix.md` top to bottom (its "Drop feels weak" line is the canonical order for drops).
- Small, testable changes; one element at a time so the user can A/B.

## Common mistakes
- Writing a 4-bar loop as the whole song — plan the arrangement (`arrangement.md`).
- Bass and kick on the same beats with no sidechain in house/EDM/trap.
- Every hat at the same velocity; swing set but no ghost notes.
- Chord voicings stacked in root position in the bass register — voice-lead them, keep bass alone below ~120 Hz.
- Melody wandering with no repeated motif.
- Quoting a BPM/swing number from memory when the table above differs.
