# Idea Generation & Co-Producer Moves

## Session starters (pick one, commit, show result in 4 bars)
1. **Drums first**: genre grid → add one melodic element → find the key from the sample/808.
2. **Chords first**: 4-chord loop in the genre's default key → bass follows → hook on top → drums last.
3. **Sample flip**: `detect_clip_key` → chop 8 slices → re-sequence 2 bars → drums under → filter.
4. **Constraint**: one instrument, one bar, 10 minutes; expand only what survives.
5. **Reference deconstruction**: pick a reference track, list its 6 elements + arrangement, rebuild with different sounds.
6. **Genre collision**: rhythm from genre A, harmony from genre B (trap drums + neo-soul chords; house kick + jazz voicings; afrobeats percussion + synthwave pads).

## Variation strategies (offer two after every deliverable)
| Axis | Moves |
|---|---|
| Rhythm | half-time ↔ double-time the drums; swing 50 → 60%; shift the snare to beat 3 only; add hat rolls; Euclidean rotate perc; remove the kick for a bar |
| Harmony | flip I–V–vi–IV → vi–IV–I–V; add 7ths/9ths; borrow iv or bVI; tritone sub the V; pedal the bass; modulate up a step for the last chorus; relative major/minor swap |
| Melody | transpose the motif to each chord; invert it; augment (double note lengths); start on the "and"; end on the 9th instead of the root; call-and-response answer |
| Bass | root-only → walking; offbeat house bass; octave jumps; 808 slides; play the 5th on the "and" of 2 |
| Sound | same MIDI, new instrument (Rhodes → pad → pluck); layer an octave up at −8 dB; LP filter one part; saturate the drum bus |
| Arrangement | strip to two elements for 4 bars; add a crash on the 1; drop the sub for the last bar; halve the section length; add a 2-bar silence before the hook |
| Space | send chords to reverb, keep drums dry; delay throw on the last note; mono the intro, wide the chorus |

## Genre-conversion recipe ("make it jazz / neo-soul / trap")
Keep the hook/melody pitches; change everything else in this order, checking each against the target column of the tables in `SKILL.md`, `drum-patterns.md`, `harmony-and-theory.md`, `sound-and-mix.md`:
1. **Tempo** → target default BPM (or keep the tempo and switch half-/double-time if the ratio is ~2:1).
2. **Drum grid** → target genre's Beats line; keep only the kick/snare *positions* that both genres share.
3. **Groove** → target swing % or late-placement; velocity shaping; remove/add ghost notes.
4. **Bass behavior** → target row in "Bassline writing" (e.g. held 808 → walking; root-on-kick → offbeat).
5. **Harmony** → same roots, target extensions/voicings (triads → 7/9/13, rootless or quartal); one borrowed chord if the target genre uses them.
6. **Instruments** → target row in "Sound choice by genre" (swap, don't add: same number of elements).
7. **Space/mix** → target reverb/delay style; sidechain on/off; saturation/lo-fi treatment.
Deliver the converted loop, then name the two things that changed the vibe most.

Worked example — pop (120, kick 1&3, snare 2&4, 8th hats, C–G–Am–F) → **neo-soul**: 80 BPM · kick @ 0, 1.75, 2.5; snare @ 1.03, 3.04 (rim in verses); hats straight 8ths v70/50; ghosts @ 0.5, 1.25, 2.5, 3.25 v35; drop the open hat · Cmaj9–G13–Am9–Fmaj9 (or reframe to Dm9–G13–Cmaj9–A7#9), quartal/rootless voicings 48–72 · bass root on 1 + chromatic approaches, 10–30 ms late · E-Piano Rhodish with tremolo, electric/upright bass, brushed hats · room + spring reverb, keep it mono-ish, no quantize.

## Producer questions to ask (only when the answer changes the work)
- "Vocal on this, or instrumental?" (decides mid-range space and key).
- "Club or headphones?" (decides sub weight and arrangement length).
- "Reference track?" (fastest alignment).
- "Loop or full song?" (decides whether to arrange now).
Otherwise: decide, deliver, offer variations.

## Breaking a block
Change tempo ±10 · flip to the relative key · mute the drums and write to the chords alone · reverse the sample · limit to 3 tracks · set the swing to 62% · start from the outro · copy the arrangement of a reference and fill it with new parts.

## A/B discipline
Change one thing, loop 8 bars, compare at matched loudness, keep or revert (`undo`). Bounce alternates with `duplicate_clip_to` into the next scene so both versions stay playable.
